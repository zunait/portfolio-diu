QuakeBR Battle Royale

A custom high-action Minecraft Battle Royale plugin engineered in Java. Features custom firearm weapons with instant raycast sniper mechanics, automatic crossbow-based assault rifles, and dynamic lobby queue management.

01

Overview

QuakeBR merges fast-paced arcade shooter mechanics inspired by classic Quake deathmatches with Minecraft's Battle Royale survival loop. Traditional Minecraft arrow projectiles suffer from travel delay and gravity arcs; QuakeBR overcomes this by utilizing vector mathematics and mathematical raytracing for immediate hitscan calculations.

The plugin acts as a comprehensive minigame engine: handling player matchmaking queues, automated countdown timers, game boundary restrictions, real-time elimination tracking, and match victory state transitions without requiring server restarts.

Weapons & Game Mechanics

Railgun (Instant Hitscan Sniper)

Inspired by Quake Arena mechanics. Uses high-frequency vector trajectory sampling to calculate instantaneous hits across long distances, producing laser visual effects and instant impact damage.

Raycast Vector Math Particle Laser Effects Damage Multipliers

AK-47 (Automatic Weapon System)

Crossbow-derived automatic rifle system with custom fire-rate tick schedulers, recoil dispersion vectors, and custom sound design to simulate tactical shooter combat inside Minecraft.

Burst Fire Scheduler Recoil Math Custom Item NBT

Lobby & Queue Management

Command-driven match flow via /qbr join, /qbr leave, and operator start commands. Manages lobby rosters, countdown sequences, and dynamic spectator routing.

Queue Engine Countdown Timers Player State Routing

Admin Testing Suite

Equipped with in-game administrative utilities (/get <ak|railgun>) allowing operators to spawn items, calibrate hitboxes, and test damage falloff on the fly.

Command Framework OP Permissions Live Debugging

Technical Takeaways

Building QuakeBR deepened my knowledge of game math, 3D coordinate vectors, entity bounding boxes, and event-driven architecture in Java. Ensuring that weapon calculations and particle simulations ran smoothly without dropping server ticks was a great exercise in performance-conscious programming.
