Overview

Code Farm is an online platform built to streamline competitive programming practice. It gives programmers a structured space to attempt coding challenges and receive immediate test case feedback.

Designed with a low-latency interactive code editor and automated test-runner runner architecture to test multiple language solutions on the fly.

React Frontend UI
Node.js Backend Runner
Vite Build Tool

Key Features

Problem Library

Curated collection of algorithmic challenges sorted by difficulty tags, data structure topics, and acceptance rates.

Interactive Code Editor

Embedded Monaco-based code editor supporting syntax highlighting, brackets pair matching, and autocomplete.

Real-Time Solution Judge

Instant execution feedback, edge case verification, execution time benchmarks, and memory limit analysis.
