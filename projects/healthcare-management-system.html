Healthcare Management System

A high-performance console-based Hospital Management System built in C. Featuring structured binary file persistence and strict role-based access control.

Overview

Healthcare Management System is a comprehensive terminal-based application developed in low-level C, designed to streamline hospital operations with a clean and intuitive CLI interface.

The system prioritizes security and organization through role-based access control, allowing isolated operational portals for Admins, Doctors, and Receptionists.
