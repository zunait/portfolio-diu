Medicine Reminder Bot

An automated notification service and dashboard that sends daily medicine reminders to family members in Bengali via Telegram, grouped by routine meal schedules and running as a persistent background daemon.

01

Overview

Designed to solve a real family healthcare issue, the Medicine Reminder Bot coordinates daily prescriptions across three essential timing sessions: morning (সকাল), noon (দুপুর), and night (রাত). It automatically groups medications by meal conditions (before meal / after meal) so elderly relatives receive straightforward, timely alerts directly on their messaging app.

The project pairs the automated Telegram distribution bot with a clean, password-protected web dashboard where family members and caregivers can easily register schedules, add or update medicines, and manage recipient lists without touching the database directly.

Python Core Language
Telegram Delivery Platform
Flask Dashboard Web App
Systemd Daemon / 24/7 Uptime
02

Key Capabilities

Automated Scheduling Engine

Leverages APScheduler running asynchronously in the background to dispatch precise session reminders for breakfast, lunch, and dinner timings without blocking HTTP requests.

APScheduler Background Workers Cron Timing

Telegram Bot Integration

Family members register simply by typing /start in Telegram. Notifications format prescription names, dosages, and instructions clearly in localized Bengali script.

Telegram Bot API i18n Bengali Auto-Registration

Management Web Dashboard

Built with Flask and SQLite, the administrative web panel enables authentication, quick addition of prescriptions, recipient grouping, and timeline adjustments with zero downtime.

Flask SQLite Session Auth

Production Server Deployment

Configured as a dedicated Linux systemd background service with automated restart policies upon reboot or failure, and live log diagnostics via journalctl.

Linux Systemd Daemon Logging & Monitoring
03

Takeaways & Impact

This project demonstrated how simple, well-structured tools solve daily problems reliably. Developing the scheduling daemon, handling timezone synchronization, and maintaining uninterrupted background processes provided deep hands-on experience in Linux service management and asynchronous Python application engineering.
